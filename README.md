# Gerenciador de Tarefas

O Gerenciador de Tarefas é um projeto desenvolvido em Java com o objetivo de praticar programação orientada a objetos (POO) e aprender a organizar melhor o código.

O sistema permite cadastrar tarefas e responsáveis, além de consultar informações por meio de um menu interativo no terminal.

## Funcionalidades

- Cadastro de responsáveis com nome, cargo e CPF.
- Cadastro de tarefas com nome, descrição, data de início e prazo final.
- Associação de tarefas a responsáveis por meio de identificadores.
- Listagem de tarefas cadastradas.
- Busca de tarefas pelo identificador.
- Listagem de responsáveis cadastrados.

## Tecnologias utilizadas

- Java
- Git
- GitHub

## Objetivo

Este projeto faz parte dos meus estudos em Java e serve como prática para trabalhar com classes, objetos, construtores, encapsulamento, listas e métodos.

O sistema ainda está em desenvolvimento e receberá novas funcionalidades e melhorias ao longo do tempo.
